# OpenClaw Assistant (fork)

This is Mykola's fork of the OpenClaw Assistant app for Home Assistant. It is the same app, built from our repository, so we choose which OpenClaw version it runs and when it updates.

- Fork: [mpiatkovskyi/OpenClawHA](https://github.com/mpiatkovskyi/OpenClawHA)
- Original: [techartdev/OpenClawHomeAssistant](https://github.com/techartdev/OpenClawHomeAssistant) by techartdev. Its README and documentation describe the app and its options.

Changes against the original are kept small: this file, `repository.yaml`, the description and panel title in `config.yaml`, and the OpenClaw version line in `Dockerfile` while the original is behind.
